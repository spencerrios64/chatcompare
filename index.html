chatcompare

Ask several AIs the same question at once and read the answers side by side. Runs in your browser with your own API keys.

Settings: API keys and models

Paste a key for each AI you want to compare, press Load models, and pick a model. Keys are stored only in this browser and are sent only to that AI's own API. Paid APIs charge your account for each question, once per AI.

Where do they differ?

The comparison is itself written by an AI, so it can be wrong or favour its own answer. It costs one more message on that AI.

Good to know

  • It uses official API keys. It cannot use your normal chatgpt.com or claude.ai login.
  • Each question is sent on its own, with no earlier conversation. Answers are plain text and arrive all at once.
  • If you already saved keys in chatrelay in this browser, they are copied here the first time, because both pages live on the same site.

Part of the same family as chatvault, chatzip and chatrelay.
